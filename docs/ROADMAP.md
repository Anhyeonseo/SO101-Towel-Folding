# 심투리얼 로드맵

목표는 카메라로 수건을 펼치고 직교 방향으로 두 번 접는 정책을 시뮬레이션에서 개발해 실제 SO101 양팔로 옮기는 것이다. 현재 상태는 [진행 상황](CURRENT_STATUS.md), 최종 대상과 품질 기준은 [수건 조작 설계](TOWEL_FOLDING.md)를 따른다.

기하 기반 제어를 기준으로 확보한 뒤, 같은 관측·행동·평가 데이터에서 모방학습, 자기지도, 모델 기반 학습, 강화학습을 비교한다. 학습 출력은 제한된 조작과 파라미터이며 알고리즘은 비교 결과에 따라 선택한다.

## 단계와 완료 기준

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| R0 작업셀 | 양팔·패드·카메라 마운트, 좌표·관절·명령 계약 | 등록 자산, 관측 자세, 가동범위와 오차의 검증 근거 확보 |
| R1 관측 | 카메라 보정, 가림·미지 상태, 영상 데이터 | 독립 관측·거절 평가 통과, episode 단위 데이터 분리 |
| **R2 시뮬레이션 기반** | **집기·연속 접기·공통 관측/행동·학습 환경** | **G0–G5 통과, 실물 비교를 위한 입력·한계·평가 항목 확보** |
| R3 실물 기본 조작 | 집기·들기·놓기·당기기·다층 집기 | 조작별 10회 중 사후 조건 9회 이상 통과, 안전 사고 0회 |
| R4 실물 두 번 접기 | 평탄·정렬한 수건의 1차/직교 2차 접기 | 각 접기 독립 20회 중 19회 이상 품질 통과, 충돌·낙하·작업대 이탈 0회 |
| R5 학습 전이·펼치기 | 제한 보정과 거친 펼치기 | 같은 행동 예산에서 규칙 기반 보정 대비 실제 승인률 개선; 펼치기 20회 중 19회 이상 목표 중간 상태 도달, 안전 사고 0회 |
| R6 평탄화·정렬 | 말린 변·숨은 겹 검사, 당기기·재집기 | 부분 펼침 20회 중 19회 이상 ALIGNED, 잘못된 겹 구조의 정렬 승인 0회 |
| R7 통합·복구 | 관측→조작→퇴피→재관측 상태기계 | 정상·오류·오래된 관측·예산 소진 모두 유한하게 종료하고 원인 기록 |
| R8 최종 평가 | 미사용 구김 상태의 전체 실행 | 실물 30회 중 27회 이상 전체 성공과 최종 형상 기준 충족 |

실물 실행은 계획 검사→무동작 검증→수건 없는 동작→감독하 단발 시험→제한 반복→통합 순서로 진행한다. 각 단계는 별도 승인 범위에서 수행하며, 시뮬레이션 통과가 모터 실행 승인을 대신하지 않는다.

## R2의 수행 순서

세부 판정은 [R2 검증 기준](R2_SIM2REAL_CONTRACT.md)에 둔다.

1. **G0 구성과 재현성:** 자산·초기화·구동·관측·판정의 입력과 책임을 명시한다. 외부 입력의 누락·해시 불일치를 거절한다.
2. **G1 구동과 접촉:** 작은 누르기·닫기·들기·놓기 시험에서 구동 제한, 반력, 관통을 구분해 검증한다.
3. **G2 집기와 관측:** 두 겹을 U자로 모은 국소 네 겹의 형성과 하중 유지를 확인하고 진단용 정답을 실제 정책 입력에서 분리한다.
4. **G3 연속 두 번 접기:** 사전 고정한 명목 조건 3회 모두 집기→1차 접기→재관측→2차 접기→놓기를 통과한다. 팔과 양쪽 손목 카메라 마운트 충돌을 포함한다.
5. **G4 오차와 실패:** 튜닝에 쓰지 않은 고정 조건 20개 이상에서 성공·실패·거절·시간을 기록한다. 실제 측정 범위와 가정한 범위를 구분한다.
6. **G5 학습 환경:** reset·observation·action·reward·termination과 데이터 분할을 고정하고, 기준 정책과 제한된 학습/rollout 실행을 검증한다.

R2는 조작 개발에 필요한 물리 반응과 평가 기반을 갖추는 단계다. 실물 집기력의 최종 식별은 R3, 실물 두 번 접기의 반복성은 R4, 학습 정책의 전이 성능은 R5에서 판정한다. 대규모 학습이나 완전한 섬유 모델은 R2 종료 조건에 포함하지 않는다.

## 실물 비교와 학습 평가

R3에서는 같은 명령의 목표·실제 관절, 영상, 사용 가능한 전류·부하를 기록하고 시뮬레이션과 비교한다. 부하 신호는 보정 없이 접촉력으로 해석하지 않는다. 확인된 차이는 R2 모델과 오차 범위에 반영한다.

R4는 각 접기 후 손을 열고 치워 새 관측을 얻는다. 보정은 최대 2회이며, 2차 접기의 한손·양손 전략은 실제 다층 집기와 마운트 충돌 검증으로 결정한다.

R5는 1차 접기 오차에 대한 최대 2회 보정부터 학습한다. 같은 평가 데이터와 행동 예산에서 규칙 기반 제어와 비교하고, 동률이면 시간과 시도 횟수를 비교한다. 거친 펼치기의 목표 중간 상태는 PARTIALLY_OPEN 또는 TWO_CORNERS_VISIBLE이다. 시뮬레이션 학습, 실물 보정, 최종 평가 데이터는 분리한다.

R7의 복구는 가림·미끄러짐·겹수 불확실·접힘 오차·추종 오류를 구분한다. 재호출로 시간·거리·횟수 예산을 초기화하지 않는다. 한 팔의 오류는 양팔 정지로 연결한다.

R8은 [최종 품질 기준](TOWEL_FOLDING.md#최종-품질-기준), 기준 정책 비교, 시뮬레이션 사용 효과, 단계별 실패율, 재연결·정지·장시간 운용을 평가한다. 평가 데이터를 추가 학습에 사용하면 새로운 평가 세트를 사용한다.
