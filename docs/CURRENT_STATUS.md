# 동결 시점의 진행 상황

동결일: 2026-09-09 · 마지막 물리 시험: 2026-09-08

이 저장소는 수건 접기 개발의 보관본이다. 아래의 다음 검증은 동결 당시 남은 과제를 기록한 것이며, 이 저장소에서 진행 중인 작업은 아니다.

**R2 미완료, 실험 일시 중단.** 현재 우선 과제는 실물과 대응되는 구동·접촉 검증(G1)이다. 2차 접기와 심투리얼 성공 결과는 아직 없다.

## 확보한 기반

| 범위 | 확보한 내용 | 검증의 한계 |
|---|---|---|
| R0 작업셀 | 양팔·카메라 마운트·관절 계약, 통신과 실행 브리지 | 구조 변경 후 경로별 도달·충돌 검사가 필요 |
| R1 관측 | 카메라 보정, 수건 영상·검수 데이터, 관측 유효성 검사 | 영상만으로 숨은 겹수나 실제 집기력을 확인할 수 없음 |
| S1 비교 결과 | 2.2 mm 패드 조건의 1차 접기 시뮬레이션과 입력 해시 | 기존 직접 관절 상태 입력과 반력 처리 때문에 실물 압착 검증으로 사용할 수 없음 |
| S2 진단 구현 | 초기화 후 위치 목표 구동, 턱 반응에 따른 하강 정지, 명령 선행 제한, 반력·관통 관측 | 접촉→들기→놓기 전체 경로 미검증 |

R0·R1은 기존 범위의 기반을 보존한 상태다. 이후 집기 구조·실행 경로의 변경까지 검증됐다는 의미는 아니다.

현재 수건 계약 검사는 통과하지만 참조하는 정적 유지 원본 4건은 로컬에서 확인되지 않으며, 자동 집기·동적 운용 한계 10개는 실물 검증 전이다.

## 최근 시험과 남은 문제

- 직접 관절 상태 입력을 제거한 단방향 결합 시험에서는 수건 면과 패드의 관통이 관측됐다.
- 반력을 적용한 양방향 결합 시험은 팔의 추종 오차가 정지 기준을 초과해 닫힘 전에 종료됐다.
- 턱 반응으로 하강을 멈추는 시험은 접촉 반응의 지속 조건을 충족하지 못했다. 명령 선행을 제한한 후속 시험은 접촉 전에 시간 예산이 소진됐다.
- 하강 예산을 조정한 최신 `local_primitive` 실행은 수동 중단됐다. 저장된 마지막 단계는 초기화 0.2초이며, 최종 상태와 녹화가 저장되지 않아 이후 동작은 판정할 수 없다.

현재 구현에는 접촉 확인 후 8 mm 들기→정지→내리기→열기→퇴피하는 진단 경로가 있다. 실행 완료, U자 네 겹 유지, 연속 S1→S2 접기는 모두 미검증이다. 시뮬레이터의 재료 ID를 사용하는 접촉 관측은 진단용이며 실물 정책 입력이 아니다.

2026-09-08 보존 기록에는 관련 단위 시험 43개 통과와 S1 보호 파일 16개의 해시 일치가 기록돼 있다. 이는 물리 집기 성공 판정과 별개다. 해당 시험의 실물 모터 명령은 0회다. 원본 식별자는 [검증 근거](EVIDENCE.md)와 [결과 요약](results/r2_checkpoint.json)에 정리했다.

## 다음 검증

1. 기존 물성·2.2 mm 패드를 유지하고 작은 눌림·닫힘·들기·놓기 시험으로 G1을 판정한다.
2. 초기화 어댑터와 실행 구성을 정리하고, U자 네 겹의 형성과 하중 유지를 검증한다.
3. 집기가 검증되면 연속 두 번 접기, 고정 변동 조건 평가, 학습 환경 검증으로 진행한다.

재개 입력은 로컬 실험 디렉터리의 `r2_contact_foundation_20260908/plan_local_primitive.json`이다. 새 출력 디렉터리를 사용하며 이전 중단 결과는 보존한다. 단계별 완료 기준은 [R2 검증 기준](R2_SIM2REAL_CONTRACT.md)과 [로드맵](ROADMAP.md)을 따른다.
